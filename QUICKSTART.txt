DAEDALUS - Identity & Context Switcher
Version 1.0.0 | January 13, 2026

=== QUICK START ===

1. INSTALL PROTON VPN CLI:
   brew install protonvpn-cli
   protonvpn config

2. COPY DAEDALUS:
   git clone https://github.com/mazze93/daedalus-switch ~/.daedalus
   mkdir -p ~/.daedalus/{daedalus,personal,creative,community}

3. MAKE EXECUTABLE:
   chmod +x ~/.daedalus/bin/*
   chmod +x ~/.daedalus/lib/*.sh

4. ADD ALIAS (~/.zshrc):
   alias daedalus="~/.daedalus/bin/daedalus"
   source ~/.zshrc

5. CREATE FOCUS MODES:
   System Preferences > Focus > +
   Create: "Security", "Creator", "Organizing"

6. CREATE SSH KEYS:
   ssh-keygen -t ed25519 -f ~/.ssh/id_rsa_security
   ssh-keygen -t ed25519 -f ~/.ssh/id_rsa_personal
   ssh-keygen -t ed25519 -f ~/.ssh/id_rsa_creative
   ssh-keygen -t ed25519 -f ~/.ssh/id_rsa_community

7. UPDATE CONFIGS:
   nano ~/.daedalus/config/daedalus.yaml
   - Update VPN server name (from: protonvpn list)
   - Update terminal.ssh_key paths
   - Update browser.urls_to_open
   - Update notifications.focus_mode
   
   Repeat for: personal.yaml, creator.yaml, organizer.yaml

8. TEST:
   daedalus switch daedalus
   daedalus status
   daedalus log

=== COMMANDS ===

daedalus switch <context>    # daedalus, personal, creator, organizer
daedalus status              # Show current context + system state
daedalus audit               # Verify OPSEC integrity
daedalus log [lines]         # View audit trail (default 20)
daedalus emergency-kill      # Full reset (requires confirmation)
daedalus help                # Show help

=== VPN SERVER NAMES ===

Run: protonvpn list

Then update configs with server names from output, e.g.:
  daedalus.yaml: vpn.server = "US#1"
  personal.yaml: vpn.server = "NL#1"

=== TROUBLESHOOTING ===

VPN won't connect:
  protonvpn status
  protonvpn connect --servername "US#1"

Focus mode not found:
  Create in System Preferences > Focus first

Browser profile missing:
  Safari: Uses iCloud sync
  Chrome: Create profile in Settings > Profiles

SSH key not found:
  ssh-keygen -t ed25519 -f ~/.ssh/id_rsa_security
  ssh-add ~/.ssh/id_rsa_security

=== ARCHITECTURE ===

~/.daedalus/
  bin/          - Executable scripts (daedalus, _switch, _vpn, _browser, _terminal, etc.)
  config/       - YAML context definitions (daedalus.yaml, personal.yaml, creator.yaml, organizer.yaml)
  lib/          - Utilities (logging.sh, config.sh, validation.sh)
  logs/         - Audit trail (audit.log - 600 perms)
  {contexts}/   - Context data directories (daedalus, personal, creative, community)

=== WHAT IT DOES ===

One command atomically:
1. Disconnects VPN → connects to context-specific server
2. Sets iTerm2 profile + SSH key + environment variables
3. Launches Safari/Chrome with context profile + URLs
4. Activates macOS Focus mode + suppresses irrelevant notifications
5. Hides other contexts' directories + enables Spotlight exclusion
6. Logs all steps with timestamps for audit trail
